## 一、待实现：`service/KnowledgeArticleService.java`

> **文件路径：** `src/main/java/com/lzc/mindaispringboot/service/KnowledgeArticleService.java`

这个 Service 包含文章的全部业务逻辑：**分页查询、新增、更新、状态流转（发布/下架）、详情（含阅读数原子自增）、删除**。

```java
package com.lzc.mindaispringboot.service;

import com.baomidou.mybatisplus.core.conditions.query.LambdaQueryWrapper;
import com.baomidou.mybatisplus.core.conditions.update.LambdaUpdateWrapper;
import com.baomidou.mybatisplus.extension.plugins.pagination.Page;
import com.lzc.mindaispringboot.common.Dto.KnowledgeArticleCreateDTO;
import com.lzc.mindaispringboot.common.Dto.KnowledgeArticlePageQuery;
import com.lzc.mindaispringboot.common.Dto.KnowledgeArticleUpdateDTO;
import com.lzc.mindaispringboot.entity.KnowledgeArticle;
import com.lzc.mindaispringboot.exception.BusionessException;
import com.lzc.mindaispringboot.mappper.KnowledgeArticleMapper;
import com.lzc.mindaispringboot.mappper.KnowledgeCategoryMapper;
import jakarta.annotation.Resource;
import org.springframework.stereotype.Service;
import org.springframework.util.StringUtils;

import java.time.LocalDateTime;
import java.util.UUID;

@Service
public class KnowledgeArticleService {
    @Resource
    private KnowledgeArticleMapper articleMapper;
    @Resource
    private KnowledgeCategoryMapper categoryMapper;

    // ==================== 1. 分页查询 ====================
    /**
     * @param query         分页 + 筛选条件（categoryId / keyword / status）
     * @param onlyPublished true=强制只看 status=1（用户端）；
     *                      false=管理员，按 query.status 实际值过滤
     */
    public Page<KnowledgeArticle> page(KnowledgeArticlePageQuery query, boolean onlyPublished) {
        LambdaQueryWrapper<KnowledgeArticle> wrapper = new LambdaQueryWrapper<>();

        // 状态过滤：用户端只看已发布，管理端按传参过滤
        if (onlyPublished) {
            wrapper.eq(KnowledgeArticle::getStatus, 1);
        } else if (query.getStatus() != null) {
            wrapper.eq(KnowledgeArticle::getStatus, query.getStatus());
        }

        // 按分类过滤
        if (query.getCategoryId() != null) {
            wrapper.eq(KnowledgeArticle::getCategoryId, query.getCategoryId());
        }

        // 关键词模糊匹配（标题 OR 摘要）
        if (StringUtils.hasText(query.getKeyword())) {
            wrapper.and(w -> w.like(KnowledgeArticle::getTitle, query.getKeyword())
                    .or().like(KnowledgeArticle::getSummary, query.getKeyword()));
        }

        // 排序：发布时间降序 → 创建时间降序（保证二级排序稳定）
        wrapper.orderByDesc(KnowledgeArticle::getPublishedAt)
               .orderByDesc(KnowledgeArticle::getCreatedAt);

        return articleMapper.selectPage(
                new Page<>(query.getPageNum(), query.getPageSize()), wrapper);
    }

    // ==================== 2. 新增文章 ====================
    public KnowledgeArticle create(KnowledgeArticleCreateDTO dto, Long authorId) {
        // 校验分类是否存在
        checkCategory(dto.getCategoryId());

        // status：前端不传或传 1 = 发布；传 0 = 草稿/下架
        boolean publish = dto.getStatus() == null || dto.getStatus() == 1;

        KnowledgeArticle article = KnowledgeArticle.builder()
                .id(UUID.randomUUID().toString())      // UUID 主键，防遍历撞库
                .categoryId(dto.getCategoryId())
                .title(dto.getTitle())
                .summary(dto.getSummary())
                .content(dto.getContent())
                .coverImage(dto.getCoverImage())
                .tags(dto.getTags())
                .authorId(authorId)
                .readCount(0)
                .status(publish ? 1 : 0)
                .publishedAt(publish ? LocalDateTime.now() : null)  // 发布时填入发布时间
                .createdAt(LocalDateTime.now())
                .updatedAt(LocalDateTime.now())
                .build();

        articleMapper.insert(article);
        return article;
    }

    // ==================== 3. 更新文章 ====================
    /**
     * 只更新 DTO 中非 null 的字段（null 字段不动原值）。
     * 传了 categoryId 则校验分类是否存在。
     */
    public KnowledgeArticle update(String id, KnowledgeArticleUpdateDTO dto) {
        KnowledgeArticle article = getArticleOrThrow(id);

        if (dto.getCategoryId() != null) {
            checkCategory(dto.getCategoryId());
            article.setCategoryId(dto.getCategoryId());
        }
        if (dto.getTitle() != null)     article.setTitle(dto.getTitle());
        if (dto.getSummary() != null)   article.setSummary(dto.getSummary());
        if (dto.getContent() != null)   article.setContent(dto.getContent());
        if (dto.getCoverImage() != null) article.setCoverImage(dto.getCoverImage());
        if (dto.getTags() != null)      article.setTags(dto.getTags());

        article.setUpdatedAt(LocalDateTime.now());
        articleMapper.updateById(article);
        return article;
    }

    // ==================== 4. 状态流转（发布 / 下架）====================
    public void updateStatus(String id, Integer status) {
        getArticleOrThrow(id);

        if (status == null || (status != 0 && status != 1)) {
            throw new BusionessException("状态值不合法（0:下架 1:发布）");
        }

        articleMapper.update(null, new LambdaUpdateWrapper<KnowledgeArticle>()
                .eq(KnowledgeArticle::getId, id)
                .set(KnowledgeArticle::getStatus, status)
                .set(status == 1, KnowledgeArticle::getPublishedAt, LocalDateTime.now()) // 转为发布时刷新时间
                .set(KnowledgeArticle::getUpdatedAt, LocalDateTime.now()));
    }

    // ==================== 5. 文章详情 ====================
    /**
     * @param checkPublished true=用户端（仅允许看已发布，否则抛异常）；
     *                       false=管理员无限制
     * 阅读数用 setSql 做数据库原子自增，比"先读-加1-再写"更安全。
     */
    public KnowledgeArticle detail(String id, boolean checkPublished) {
        KnowledgeArticle article = getArticleOrThrow(id);

        if (checkPublished && (article.getStatus() == null || article.getStatus() != 1)) {
            throw new BusionessException("文章不存在或未发布");
        }

        // 原子自增阅读数（避免并发时读-写竞争）
        articleMapper.update(null, new LambdaUpdateWrapper<KnowledgeArticle>()
                .eq(KnowledgeArticle::getId, id)
                .setSql("read_count = read_count + 1"));

        article.setReadCount(article.getReadCount() == null
                ? 1 : article.getReadCount() + 1);
        return article;
    }

    // ==================== 6. 删除文章 ====================
    public void delete(String id) {
        getArticleOrThrow(id);
        articleMapper.deleteById(id);
    }

    // ==================== 内部辅助方法 ====================

    private KnowledgeArticle getArticleOrThrow(String id) {
        KnowledgeArticle article = articleMapper.selectById(id);
        if (article == null) {
            throw new BusionessException("文章不存在");
        }
        return article;
    }

    private void checkCategory(Long categoryId) {
        if (categoryMapper.selectById(categoryId) == null) {
            throw new BusionessException("文章分类不存在");
        }
    }
}
```

package com.lzc.mindaispringboot.controller;

import com.baomidou.mybatisplus.extension.plugins.pagination.Page;
import com.lzc.mindaispringboot.Aop.GetToken;
import com.lzc.mindaispringboot.Aop.Token_Aspect;
import com.lzc.mindaispringboot.common.Dto.KnowledgeArticleCreateDTO;
import com.lzc.mindaispringboot.common.Dto.KnowledgeArticlePageQuery;
import com.lzc.mindaispringboot.common.Dto.KnowledgeArticleStatusDTO;
import com.lzc.mindaispringboot.common.Dto.KnowledgeArticleUpdateDTO;
import com.lzc.mindaispringboot.common.Result;
import com.lzc.mindaispringboot.entity.KnowledgeArticle;
import com.lzc.mindaispringboot.response.CategoryTreeNode;
import com.lzc.mindaispringboot.service.KnowledgeArticleService;
import com.lzc.mindaispringboot.service.KnowledgeCategoryService;
import com.lzc.mindaispringboot.util.AuthUtil;
import jakarta.annotation.Resource;
import jakarta.validation.Valid;
import org.springframework.security.access.prepost.PreAuthorize;
import org.springframework.web.bind.annotation.*;

import java.util.List;

@RestController
@RequestMapping("/api/knowledge")
public class KnowledgeController {

    private KnowledgeCategoryService categoryService;
    @Resource
    private KnowledgeArticleService articleService;

    // ======================== 管理端接口 ========================

    /** 管理端：获取分类树（供后台下拉选择分类用） */
    @GetToken
    @PreAuthorize("hasRole('2')")
    @GetMapping("/category/tree")
    public Result<List<CategoryTreeNode>> categoryTree() {
        return Result.success(categoryService.getTree());
    }

    /** 管理端：新增文章 */
    @GetToken
    @PreAuthorize("hasRole('2')")
    @PostMapping("/article")
    public Result<KnowledgeArticle> addArticle(@Valid @RequestBody KnowledgeArticleCreateDTO dto) {
        Long userId = Token_Aspect.getUserId();
        return Result.success(articleService.create(dto, userId));
    }

    /** 管理端：更新文章（只覆盖非 null 字段） */
    @GetToken
    @PreAuthorize("hasRole('2')")
    @PutMapping("/article/{id}")
    public Result<KnowledgeArticle> updateArticle(
            @PathVariable String id,
            @Valid @RequestBody KnowledgeArticleUpdateDTO dto) {
        return Result.success(articleService.update(id, dto));
    }

    /** 管理端：发布 / 下架 */
    @GetToken
    @PreAuthorize("hasRole('2')")
    @PutMapping("/article/{id}/status")
    public Result<Void> updateArticleStatus(
            @PathVariable String id,
            @Valid @RequestBody KnowledgeArticleStatusDTO dto) {
        articleService.updateStatus(id, dto.getStatus());
        return Result.success();
    }

    /** 管理端：删除文章 */
    @GetToken
    @PreAuthorize("hasRole('2')")
    @DeleteMapping("/article/{id}")
    public Result<Void> deleteArticle(@PathVariable String id) {
        articleService.delete(id);
        return Result.success();
    }

    // ======================== 管理端/用户端 共用接口 ========================

    /**
     * 文章分页列表。
     * 管理员：可传 status 过滤 0/1，看全量；
     * 普通用户：强制只看已发布（status=1）。

    @GetMapping("/article/page")

        return Result.success(articleService.page(query, onlyPublished));
    }

    /**
     * 文章详情。
     * 管理员：任意状态可看；
     * 普通用户：仅允许已发布（否则抛 BusionessException）。
     * 阅读数 +1（数据库原子自增）。
     */
    @GetToken
    @GetMapping("/article/{id}")
    public Result<KnowledgeArticle> articleDetail(@PathVariable String id) {
        return Result.success(articleService.detail(id, !AuthUtil.isAdmin()));
    }

## 三、接口调用逻辑详解

### 3.1 请求进入后经过的组件链路

```
HTTP 请求
  ↓
① JwtAuthticationFilter
    验签 token → 查用户状态 → 设置 SecurityContext（含 ROLE_2）
  ↓
② Token_Aspect（@GetToken 注解触发）
    从 request header "token" 取 JWT → 解析 userId → 放入 ThreadLocal
  ↓
③ @PreAuthorize("hasRole('2')")
    非管理员 → 403 Forbidden
  ↓
④ Controller 方法体
    调 Service → 调 Mapper → 返回 Result
  ↓
⑤ Token_Aspect finally 块
    清理 ThreadLocal（防止内存泄漏）
```

### 3.2 8 个接口逐个分析

---

#### 接口 1：`GET /api/knowledge/category/tree` — 获取分类树

| 项 | 内容 |
|---|---|
| 鉴权 | `@PreAuthorize("hasRole('2')")` → 仅管理员 |
| 入参 | 无 |
| 返回 | `Result<List<CategoryTreeNode>>`，children 递归嵌套子分类 |

**执行流程：**
1. `KnowledgeCategoryService.getTree()` 查 `knowledge_category` 表 `WHERE status=1 ORDER BY sort_order`
2. 在内存中把平铺列表组装成树：`parent_id=0` / `NULL` 的作为根节点，其余挂到对应父节点下
3. 父节点缺失的兜底：也作为根节点（防止数据库脏数据导致树不完整）

---

#### 接口 2：`GET /api/knowledge/article/page` — 分页查询（管理端/用户端共用）

| 项 | 内容 |
|---|---|
| 鉴权 | 登录即可（`@GetToken`），代码内按 `AuthUtil.isAdmin()` 区分角色 |
| Query 参数 | `pageNum`（默认1）、`pageSize`（默认10）、`categoryId`、`keyword`、`status` |
| 管理员行为 | 可传 `status=0` 看下架、`status=1` 看已发布、不传看全量 |
| 普通用户行为 | **忽略** `status` 参数，强制 `status=1`（只看已发布） |
| 排序 | `published_at DESC, created_at DESC` |

**执行流程：**
1. Spring MVC 把 URL `?pageNum=1&categoryId=1&keyword=焦虑` 自动绑定到 `KnowledgeArticlePageQuery` 的同名字段
2. Controller 调 `AuthUtil.isAdmin()` → 传入 `onlyPublished` 标志
3. Service 构建 `LambdaQueryWrapper`：① 状态过滤 ② 分类过滤 ③ 关键词模糊（标题 OR 摘要）
4. 调用 `articleMapper.selectPage(Page, wrapper)` 返回 MyBatis-Plus `Page<T>`

---

#### 接口 3：`POST /api/knowledge/article` — 新增文章

| 项 | 内容 |
|---|---|
| 鉴权 | `@PreAuthorize("hasRole('2')")` → 仅管理员 |
| Request Body | `categoryId`（必填）、`title`（必填 ≤200）、`content`（必填）、`summary`（≤2000）、`coverImage`（≤500）、`tags`（≤500）、`status`（可选，默认1） |
| 返回 | 插入后的完整 `KnowledgeArticle` 实体（含 UUID 主键） |

**执行流程：**
1. `@Valid` 触发 JSR-303 校验 → 不通过返回 400
2. `Token_Aspect.getUserId()` 取当前登录管理员 ID 作为 `authorId`
3. 校验 `categoryId` 对应的分类是否存在
4. 生成 `UUID.randomUUID().toString()` 作为主键（防遍历撞库，不用自增 ID）
5. `readCount = 0`；如果 `status` 为 `null` 或 `1` → 发布 → 补 `publishedAt = now`
6. `insert` 入库，返回完整实体

---

#### 接口 4：`PUT /api/knowledge/article/{id}` — 更新文章

| 项 | 内容 |
|---|---|
| 鉴权 | `@PreAuthorize("hasRole('2')")` → 仅管理员 |
| Request Body | **全部可选**：`categoryId` / `title` / `summary` / `content` / `coverImage` / `tags`（null 的不更新） |
| 返回 | 更新后的完整 `KnowledgeArticle` 实体 |

**执行流程：**
1. `selectById(id)` 校验文章存在
2. 如果 DTO 中 `categoryId != null`，校验分类存在并覆盖
3. 其他字段非 null 即覆盖（null 跳过不动原值）
4. 刷新 `updatedAt = now`
5. `updateById` 入库

---

#### 接口 5：`PUT /api/knowledge/article/{id}/status` — 状态流转（发布/下架）

| 项 | 内容 |
|---|---|
| 鉴权 | `@PreAuthorize("hasRole('2')")` → 仅管理员 |
| Request Body | `{ "status": 1 }` 或 `{ "status": 0 }` |
| 返回 | `Result<Void>`（无 data） |

**执行流程：**
1. `@Valid` 校验 status 不为 null
2. 文章存在性校验
3. 业务校验：status 只能是 0 或 1，否则抛 `BusionessException`
4. `LambdaUpdateWrapper.set(status == 1, publishedAt, now)` — **只在转为发布时刷新 `publishedAt`**（下架不动发布时间）
5. 刷新 `updatedAt`

---

#### 接口 6：`GET /api/knowledge/article/{id}` — 文章详情（共用）

| 项 | 内容 |
|---|---|
| 鉴权 | 登录即可 |
| 管理员行为 | 任意 status 可看，阅读数 +1 |
| 普通用户行为 | status ≠ 1 → 抛 `BusionessException("文章不存在或未发布")`，阅读数 +1 |
| 返回 | `KnowledgeArticle` 实体 |

**执行流程：**
1. `selectById(id)` 校验存在
2. 如果是普通用户 && 文章非已发布 → 抛异常（防止通过遍历 ID 撞到未发布文章）
3. **阅读数原子自增：** `setSql("read_count = read_count + 1")` — 用数据库行锁保证并发安全，不会和 `selectById` 的旧值冲突
4. 返回时手动把 `readCount` +1（因为第 3 步是 update 后的值回写了数据库，但当前内存对象还是旧的）

---

#### 接口 7：`DELETE /api/knowledge/article/{id}` — 删除文章

| 项 | 内容 |
|---|---|
| 鉴权 | `@PreAuthorize("hasRole('2')")` → 仅管理员 |
| 返回 | `Result<Void>` |
| 备注 | 如果 `user_favorite` 表有 `ON DELETE CASCADE` 外键，收藏记录自动级联删除 |

**执行流程：**
1. 文章存在性校验
2. `deleteById(id)` 删除

## 四、角色区分策略总结

知识文章模块**没有**单独的"用户端接口"和"管理端接口"两套 Controller，而是在**同一套接口**中通过 `AuthUtil.isAdmin()` 在代码内区分行为：

| 接口 | 管理员行为 | 普通用户行为 |
|---|---|---|
| 分类树 | `GET /category/tree`（`@PreAuthorize` 拦截，用户打不开） | 403 |
| 文章分页 | 可看全量、可按 status 过滤 | 强制只看 status=1 |
| 文章详情 | 任意状态可看 | 只看已发布，否则抛异常 |
| 新增/更新/删除/状态 | `@PreAuthorize` 拦截，用户打不开 | 403 |

核心就是一句：`boolean onlyPublished = !AuthUtil.isAdmin();`，传入 Service，Service 按标志决定是否过滤 status。

## 五、自测建议

按以下顺序逐个验证：

1. **管理员登录** `POST /api/user/login` → 拿到 token
2. **分类树** `GET /api/knowledge/category/tree` → 确认能正常返回树
3. **新增文章** `POST /api/knowledge/article` → 确认返回 UUID 主键 + publishedAt 已填充
4. **分页查询（管理员）** `GET /api/knowledge/article/page` → 确认能看到刚新增的文章
5. **下架文章** `PUT /api/knowledge/article/{id}/status { "status": 0 }` → 确认下架成功
6. **详情（管理员）** `GET /api/knowledge/article/{id}` → 管理员仍能看到下架文章
