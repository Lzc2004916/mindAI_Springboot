## 一、通用约定（所有接口都遵守）

### 1.1 统一响应
所有接口返回 `Result<T>`：

```json
{ "code": "200", "msg": "操作成功", "data": { } }
```

- 成功：`Result.success(data)`，code=`200`
- 业务失败：抛 `BusionessException("提示")`，由 `GlobarExceptionHandler` 统一转成 `Result.error`
- 参数校验失败（`@Valid`）：由全局处理器返回 code=`400`

### 1.2 鉴权方式
| 项 | 说明 |
|---|---|
| 请求头 | `token: <JWT裸串>`（**与现有 `JwtTokenUtil.extractTokenFromRequest` 一致**，header 名就是 `token`，不带 `Bearer ` 前缀） |
| 需登录 | 除 `/api/user/login`、`/api/user/add`、`/files/**` 外全部需要 |
| 管理端 | 登录 + JWT 中 `roleType=2`。过滤器会设置 `ROLE_2` 权限，控制器上加 `@PreAuthorize("hasRole('2')")`（项目已开 `@EnableMethodSecurity`） |
| 用户端 | 登录即可，通过 `Token_Aspect.getUserId()` 取当前用户，且只能操作自己的数据（代码内做归属校验） |

> ⚠️ 注意：`application.yml` 里写的 `jwt.header: Authorization` / `token-prefix: "Bearer "` 目前是**死配置**，实际代码只认 `token` 头。本文档按现有代码行为（`token` 头、裸 JWT）编写，前端请按此发请求。

### 1.3 分页响应
分页接口直接返回 MyBatis-Plus 的 `Page<T>`，序列化后：

```json
{ "records": [ ... ], "total": 100, "size": 10, "current": 1, "pages": 10 }
```

### 2.6 修改 `util/JwtAuthticationFilter.java`（完整文件，新增登出黑名单校验）

在原有基础上只加了两处：注入 `TokenBlacklistService`、第 2 步黑名单校验。

```java
package com.lzc.mindaispringboot.util;

import com.lzc.mindaispringboot.common.ResultCode;
import com.lzc.mindaispringboot.config.SecurityConfig;
import com.lzc.mindaispringboot.response.UserLoginResponseDTO;
import com.lzc.mindaispringboot.service.TokenBlacklistService;
import com.lzc.mindaispringboot.service.UserService;
import jakarta.annotation.Resource;
import jakarta.servlet.FilterChain;
import jakarta.servlet.ServletException;
import jakarta.servlet.http.HttpServletRequest;
import jakarta.servlet.http.HttpServletResponse;
import org.springframework.security.authentication.UsernamePasswordAuthenticationToken;
import org.springframework.security.core.authority.SimpleGrantedAuthority;
import org.springframework.security.core.context.SecurityContextHolder;
import org.springframework.util.StringUtils;
import org.springframework.web.filter.OncePerRequestFilter;

import java.io.IOException;
import java.util.Collections;

public class JwtAuthticationFilter extends OncePerRequestFilter {
    @Resource
    public UserService userService;
    @Resource
    public TokenBlacklistService tokenBlacklistService;

    @Override
    protected boolean shouldNotFilter(HttpServletRequest request) throws ServletException {
        String requestURI = request.getRequestURI();
        return SecurityConfig.isPublicPATH(requestURI);
    }

    @Override
    protected void doFilterInternal(HttpServletRequest request, HttpServletResponse response, FilterChain filterChain) throws ServletException, IOException {
        String token = JwtTokenUtil.extractTokenFromRequest(request);

        // 1. 无 token，拒绝
        if (!StringUtils.hasText(token)) {
            clearSecurityContext();
            ResponseUtil.writeResponse(response, ResultCode.ACCESS_UNAUTHORIZED);
            return;
        }

        // 2. 已退出登录（黑名单）的 token 直接拒绝
        if (tokenBlacklistService.isBlocked(token)) {
            clearSecurityContext();
            ResponseUtil.writeResponse(response, ResultCode.TOKEN_BLOCKED);
            return;
        }

        // 3. 验证 token
        JwtTokenUtil.TokenVerificationResult TokenResult = JwtTokenUtil.validateToken(token);
        // 4. claims 残缺，拒绝
        if (TokenResult == null || !TokenResult.isToken()) {
            clearSecurityContext();
            ResponseUtil.writeResponse(response, ResultCode.TOKEN_INVALID);
            return;
        }
        // 5. 查用户，状态异常则拒绝
        UserLoginResponseDTO.UserDetailResponseDTO user = userService.getUserById(TokenResult.getUserId());
        if (user == null || !UserStatus.NORMAL.getCode().equals(user.getStatus())) {
            clearSecurityContext();
            ResponseUtil.writeResponse(response, ResultCode.TOKEN_ACCESS_FORBIDDEN);
            return;
        }

        // 6. 认证通过，设置 Spring Security 上下文
        UsernamePasswordAuthenticationToken authentication = new UsernamePasswordAuthenticationToken(
                TokenResult.getUsername(),
                null,
                Collections.singletonList(new SimpleGrantedAuthority("ROLE_" + TokenResult.getRoleType()))
        );
        SecurityContextHolder.getContext().setAuthentication(authentication);

        filterChain.doFilter(request, response);
    }

    private void clearSecurityContext(){
        SecurityContextHolder.clearContext();
    }
}
```

### 2.7 新增 `service/TokenBlacklistService.java`（登出用，内存版，不引新依赖）

```java
package com.lzc.mindaispringboot.service;

import org.springframework.stereotype.Service;

import java.util.Map;
import java.util.concurrent.ConcurrentHashMap;

/**
 * token 黑名单（退出登录用）。内存版：重启后黑名单清空，
 * 因 token 本身有 24h 过期时间，重启丢失的影响只是"已退出"的 token 最多再活到自然过期。
 * 后续要集群可换 Redis（引入 Redis 依赖即可，不需要新框架）。
 */
@Service
public class TokenBlacklistService {
    private final Map<String, Long> blacklist = new ConcurrentHashMap<>();

    /** 拉黑 token 到指定时间戳（毫秒） */
    public void add(String token, long expireAtMillis) {
        cleanUp();
        blacklist.put(token, expireAtMillis);
    }

    public boolean isBlocked(String token) {
        Long expireAt = blacklist.get(token);
        if (expireAt == null) return false;
        if (expireAt < System.currentTimeMillis()) {
            blacklist.remove(token);
            return false;
        }
        return true;
    }

    private void cleanUp() {
        long now = System.currentTimeMillis();
        blacklist.entrySet().removeIf(e -> e.getValue() < now);
    }
}
```

### 2.8 新增 `util/AuthUtil.java`（判断当前请求是否管理员）

```java
package com.lzc.mindaispringboot.util;

import org.springframework.security.core.Authentication;
import org.springframework.security.core.context.SecurityContextHolder;

public class AuthUtil {
    /** 当前请求是否管理员（JwtAuthticationFilter 会按 roleType 设置 ROLE_2） */
    public static boolean isAdmin() {
        Authentication auth = SecurityContextHolder.getContext().getAuthentication();
        if (auth == null) return false;
        return auth.getAuthorities().stream()
                .anyMatch(a -> "ROLE_2".equals(a.getAuthority()));
    }
}
```

```java
package com.lzc.mindaispringboot.service;

import com.baomidou.mybatisplus.core.conditions.query.LambdaQueryWrapper;
import com.lzc.mindaispringboot.entity.KnowledgeCategory;
import com.lzc.mindaispringboot.mappper.KnowledgeCategoryMapper;
import com.lzc.mindaispringboot.response.CategoryTreeNode;
import jakarta.annotation.Resource;
import org.springframework.stereotype.Service;

import java.util.ArrayList;
import java.util.LinkedHashMap;
import java.util.List;
import java.util.Map;

@Service
public class KnowledgeCategoryService {
    @Resource
    private KnowledgeCategoryMapper categoryMapper;

    /** 查询启用分类并组树（parent_id=0 或 NULL 为根） */
    public List<CategoryTreeNode> getTree() {
        List<KnowledgeCategory> all = categoryMapper.selectList(new LambdaQueryWrapper<KnowledgeCategory>()
                .eq(KnowledgeCategory::getStatus, 1)
                .orderByAsc(KnowledgeCategory::getSortOrder));
        Map<Long, CategoryTreeNode> nodeMap = new LinkedHashMap<>();
        for (KnowledgeCategory c : all) {
            nodeMap.put(c.getId(), CategoryTreeNode.builder()
                    .id(c.getId()).parentId(c.getParentId())
                    .categoryName(c.getCategoryName()).categoryCode(c.getCategoryCode())
                    .description(c.getDescription()).sortOrder(c.getSortOrder())
                    .children(new ArrayList<>()).build());
        }
        List<CategoryTreeNode> roots = new ArrayList<>();
        for (CategoryTreeNode node : nodeMap.values()) {
            if (node.getParentId() == null || node.getParentId() == 0) {
                roots.add(node);
            } else {
                CategoryTreeNode parent = nodeMap.get(node.getParentId());
                if (parent != null) parent.getChildren().add(node);
                else roots.add(node);
            }
        }
        return roots;
    }
}
```

```java
package com.lzc.mindaispringboot.service;

import com.baomidou.mybatisplus.core.conditions.query.LambdaQueryWrapper;
import com.baomidou.mybatisplus.core.conditions.update.LambdaUpdateWrapper;
import com.baomidou.mybatisplus.extension.plugins.pagination.Page;
import com.lzc.mindaispringboot.common.Dto.KnowledgeArticleCreateDTO;
import com.lzc.mindaispringboot.common.Dto.KnowledgeArticlePageQuery;

import com.lzc.mindaispringboot.exception.BusionessException;
import com.lzc.mindaispringboot.mappper.KnowledgeArticleMapper;
import com.lzc.mindaispringboot.mappper.KnowledgeCategoryMapper;
import jakarta.annotation.Resource;
import org.springframework.stereotype.Service;
import org.springframework.util.StringUtils;

import java.time.LocalDateTime;
import java.util.UUID;

@Service
public class KnowledgeArticleService {
    @Resource
    private KnowledgeArticleMapper articleMapper;
    @Resource
    private KnowledgeCategoryMapper categoryMapper;

    /** 分页查询。onlyPublished=true（用户端）强制只看已发布 */
    public Page<KnowledgeArticle> page(KnowledgeArticlePageQuery query, boolean onlyPublished) {
        LambdaQueryWrapper<KnowledgeArticle> wrapper = new LambdaQueryWrapper<>();
        if (onlyPublished) {
            wrapper.eq(KnowledgeArticle::getStatus, 1);
        } else if (query.getStatus() != null) {
            wrapper.eq(KnowledgeArticle::getStatus, query.getStatus());
        }
        if (query.getCategoryId() != null) {
            wrapper.eq(KnowledgeArticle::getCategoryId, query.getCategoryId());
        }
        if (StringUtils.hasText(query.getKeyword())) {
            wrapper.and(w -> w.like(KnowledgeArticle::getTitle, query.getKeyword())
                    .or().like(KnowledgeArticle::getSummary, query.getKeyword()));
        }
        wrapper.orderByDesc(KnowledgeArticle::getPublishedAt).orderByDesc(KnowledgeArticle::getCreatedAt);
        return articleMapper.selectPage(new Page<>(query.getPageNum(), query.getPageSize()), wrapper);
    }

    public KnowledgeArticle create(KnowledgeArticleCreateDTO dto, Long authorId) {
        checkCategory(dto.getCategoryId());
        boolean publish = dto.getStatus() == null || dto.getStatus() == 1;
        KnowledgeArticle article = KnowledgeArticle.builder()
                .id(UUID.randomUUID().toString())
                .categoryId(dto.getCategoryId())
                .title(dto.getTitle())
                .summary(dto.getSummary())
                .content(dto.getContent())
                .coverImage(dto.getCoverImage())
                .tags(dto.getTags())
                .authorId(authorId)
                .readCount(0)
                .status(publish ? 1 : 0)
                .publishedAt(publish ? LocalDateTime.now() : null)
                .createdAt(LocalDateTime.now())
                .updatedAt(LocalDateTime.now())
                .build();
        articleMapper.insert(article);
        return article;
    }

    public KnowledgeArticle update(String id, KnowledgeArticleUpdateDTO dto) {
        KnowledgeArticle article = getArticleOrThrow(id);
        if (dto.getCategoryId() != null) checkCategory(dto.getCategoryId());
        if (dto.getTitle() != null) article.setTitle(dto.getTitle());
        if (dto.getSummary() != null) article.setSummary(dto.getSummary());
        if (dto.getContent() != null) article.setContent(dto.getContent());
        if (dto.getCoverImage() != null) article.setCoverImage(dto.getCoverImage());
        if (dto.getTags() != null) article.setTags(dto.getTags());
        article.setUpdatedAt(LocalDateTime.now());
        articleMapper.updateById(article);
        return article;
    }

    public void updateStatus(String id, Integer status) {
        getArticleOrThrow(id);
        if (status == null || (status != 0 && status != 1)) {
            throw new BusionessException("状态值不合法（0:下架 1:发布）");
        }
        articleMapper.update(null, new LambdaUpdateWrapper<KnowledgeArticle>()
                .eq(KnowledgeArticle::getId, id)
                .set(KnowledgeArticle::getStatus, status)
                .set(status == 1, KnowledgeArticle::getPublishedAt, LocalDateTime.now())
                .set(KnowledgeArticle::getUpdatedAt, LocalDateTime.now()));
    }

    /** 详情；checkPublished=true（用户端）仅允许已发布，同时阅读数+1 */
    public KnowledgeArticle detail(String id, boolean checkPublished) {
        KnowledgeArticle article = getArticleOrThrow(id);
        if (checkPublished && (article.getStatus() == null || article.getStatus() != 1)) {
            throw new BusionessException("文章不存在或未发布");
        }
        articleMapper.update(null, new LambdaUpdateWrapper<KnowledgeArticle>()
                .eq(KnowledgeArticle::getId, id)
                .setSql("read_count = read_count + 1"));
        article.setReadCount(article.getReadCount() == null ? 1 : article.getReadCount() + 1);
        return article;
    }

    public void delete(String id) {
        getArticleOrThrow(id);
        articleMapper.deleteById(id); // user_favorite 由外键 ON DELETE CASCADE 级联删除
    }

    private KnowledgeArticle getArticleOrThrow(String id) {
        KnowledgeArticle article = articleMapper.selectById(id);
        if (article == null) throw new BusionessException("文章不存在");
        return article;
    }

    private void checkCategory(Long categoryId) {
        if (categoryMapper.selectById(categoryId) == null) {
            throw new BusionessException("文章分类不存在");
        }
    }
}
```

```java
import com.lzc.mindaispringboot.entity.SysFileInfo;

import jakarta.annotation.Resource;
import org.springframework.beans.factory.annotation.Value;
import org.springframework.stereotype.Service;
import org.springframework.web.multipart.MultipartFile;

import java.io.IOException;
import java.nio.file.Files;
import java.nio.file.Path;
import java.nio.file.Paths;
import java.nio.file.StandardCopyOption;
import java.time.LocalDateTime;
import java.util.List;
import java.util.UUID;

@Service
public class FileService {
    @Resource
    private SysFileInfoMapper fileMapper;

    @Value("${app.upload.dir:./uploads}")
    private String uploadDir;

    public SysFileInfo upload(MultipartFile file, String businessType, String businessId, Long uploadUserId) {
        if (file == null || file.isEmpty()) {
            throw new BusionessException("上传文件不能为空");
        }
        String originalName = file.getOriginalFilename() == null ? "unknown" : file.getOriginalFilename();
        String ext = "";
        int dot = originalName.lastIndexOf('.');
        if (dot >= 0) ext = originalName.substring(dot + 1).toLowerCase();
        String fileType = resolveFileType(ext);
        // 磁盘文件名用 UUID，防止重名/路径穿越
        String storedName = UUID.randomUUID().toString().replace("-", "") + (ext.isEmpty() ? "" : "." + ext);
        try {
            Path dir = Paths.get(uploadDir).toAbsolutePath();
            Files.createDirectories(dir);
            Files.copy(file.getInputStream(), dir.resolve(storedName), StandardCopyOption.REPLACE_EXISTING);
        } catch (IOException e) {
            throw new BusionessException("文件保存失败");
        }
        SysFileInfo info = SysFileInfo.builder()
                .originalName(originalName)
                .filePath(storedName)
                .fileSize(file.getSize())
                .fileType(fileType)
                .businessType(businessType)
                .businessId(businessId)
                .uploadUserId(uploadUserId)
                .isTemp(0)
                .status(1)
                .createTime(LocalDateTime.now())
                .build();
        fileMapper.insert(info);
        return info;
    }

    private String resolveFileType(String ext) {
        if (List.of("jpg", "jpeg", "png", "gif", "bmp", "webp").contains(ext)) return "IMG";
        if (ext.equals("pdf")) return "PDF";
        if (List.of("txt", "md").contains(ext)) return "TXT";
        if (List.of("doc", "docx").contains(ext)) return "DOC";
        if (List.of("xls", "xlsx", "csv").contains(ext)) return "XLS";
        return "OTHER";
    }
}
```

```java
import org.springframework.ai.chat.client.ChatClient;
import org.springframework.beans.factory.annotation.Autowired;
import org.springframework.beans.factory.annotation.Qualifier;
import org.springframework.stereotype.Service;
import reactor.core.publisher.Flux;

import java.time.LocalDateTime;
import java.util.List;

@Service
public class PsychologicalSupportService {
    @Autowired
    @Qualifier("open-ai")
    private ChatClient chatClient;
    @Resource
    private ConsultationSessionService consultationSessionService;
    @Resource
    private ConsultationMessageService consultationMessageService;

    public StructOutPut.StreamChatSession startSession(Long userId, ConsultationSessionCreateDto consultationSessionCreateDto){
        ConsultationSession session = consultationSessionService.createSession(userId, consultationSessionCreateDto);
        consultationMessageService.saveUserMessage(session.getId(), consultationSessionCreateDto.getInitialMessage(), null);
        String sessionId = "session_" + session.getId();
        return new StructOutPut.StreamChatSession(
                sessionId,
                userId,
                consultationSessionCreateDto.getInitialMessage(),
                System.currentTimeMillis(),
                System.currentTimeMillis() + 24 * 60 * 60 * 1000, //24小时
                1,
                "ACTIVE"
        );
    }

    public Flux<String> streamPsychologicalChat(String sessionId, String userMessage) {
        return Flux.create(sink -> {
            Long dbSession = extractSessionId(sessionId);
            if (dbSession == null) {
                sink.error(new RuntimeException("会话ID格式错误"));
                return;
            }
            boolean isInitMessage = false;
            Integer messageCount = consultationMessageService.getMessageCount(dbSession);
            if (messageCount == 1) {
                ConsultationMessageResponseDTO lastMessage =
                        consultationMessageService.getLastMessageBySessionId(dbSession);
                if (lastMessage != null
                        && lastMessage.getSenderType().equals(1)
                        && userMessage.equals(lastMessage.getContent())) {
                    isInitMessage = true;
                }
            }
            if (!isInitMessage) {
                consultationMessageService.saveUserMessage(dbSession, userMessage, null);
            }
            String conversationId = "conversation_" + sessionId;
            StrBuilder fullResponse = new StrBuilder();
            chatClient.prompt()
                    .user(userMessage)
                    .advisors(advisorSpec ->
                            advisorSpec.param("chat_memory_conversation_id", conversationId))
                    .stream()
                    .content()
                    .doOnNext(fragment -> {
                        fullResponse.append(fragment);
                        sink.next(fragment);
                    })
                    .doOnComplete(() -> {
                        String completeRes = fullResponse.toString();
                        consultationMessageService.saveAiMessage(dbSession, completeRes, "openai");
                        sink.complete();
                    })
                    .doOnError(sink::error)
                    .subscribe();
        });
    }

    // ==================== 新增：会话情绪分析 ====================

    /**
     * 获取会话情绪分析（24 小时缓存）。
     * 缓存未过期 → 直接读 consultation_session.last_emotion_analysis；
     * 过期/为空 → 拉取会话消息让 AI 做结构化分析，结果落库后返回。
     */
    public StructOutPut.EmotionAnalysis getEmotionAnalysis(String sessionId, Long userId, boolean isAdmin) {
        Long dbSession = extractSessionId(sessionId);
        if (dbSession == null) throw new BusionessException("会话ID格式错误");
        ConsultationSession session = consultationSessionService.getById(dbSession);
        if (session == null) throw new BusionessException("会话不存在");
        if (!isAdmin && !session.getUserId().equals(userId)) {
            throw new BusionessException("无权访问该会话");
        }
        // 24 小时内的分析结果直接复用，避免重复消耗 AI tokens
        if (session.getLastEmotionAnalysis() != null && session.getLastEmotionUpdatedAt() != null
                && session.getLastEmotionUpdatedAt().isAfter(LocalDateTime.now().minusHours(24))) {
            return JSONUtil.toBean(session.getLastEmotionAnalysis(), StructOutPut.EmotionAnalysis.class);
        }
        StructOutPut.EmotionAnalysis analysis = analyzeSessionEmotion(dbSession);
        session.setLastEmotionAnalysis(JSONUtil.toJsonStr(analysis));
        session.setLastEmotionUpdatedAt(LocalDateTime.now());
        consultationSessionService.updateById(session);
        return analysis;
    }

    /** 拉取会话消息 → 拼接对话 → AI 结构化情绪分析 */
    private StructOutPut.EmotionAnalysis analyzeSessionEmotion(Long dbSessionId) {
        List<ConsultationMessageResponseDTO> messages = consultationMessageService.listBySession(dbSessionId);
        if (messages.isEmpty()) throw new BusionessException("该会话暂无消息，无法进行情绪分析");
        StrBuilder dialogue = new StrBuilder();
        for (ConsultationMessageResponseDTO m : messages) {
            dialogue.append(m.getSenderType() == 1 ? "用户：" : "AI：").append(m.getContent()).append("\n");
        }
        // 超长截断（保留最近 8000 字符），避免超过模型上下文
        String text = dialogue.length() > 8000 ? dialogue.substring(dialogue.length() - 8000) : dialogue.toString();
        // .system() 覆盖 ChatClient 默认系统提示词，.entity() 走结构化输出
        return chatClient.prompt()
                .system(PromptManage.EMOTION_ANALYSIS_PROMPT)
                .user(text)
                .call()
                .entity(StructOutPut.EmotionAnalysis.class);
    }

    public Long extractSessionId(String sessionId){
        if (sessionId == null || !sessionId.startsWith("session_")) return null;
        return Long.parseLong(sessionId.replace("session_",""));
    }
}
```

**实现流程：** ① `extractDbSessionId` 解析主键 → ② `checkOwnership`：查会话，不存在或 `user_id != 当前用户` 抛业务异常 → ③ `listBySession` 按时间升序返回消息 DTO 列表。

#### G-3 获取会话情绪分析结果 `GET /api/psychological-chat/session/{sessionId}/emotion`
| 项 | 内容 |
|---|---|
| 鉴权 | 登录（用户只能分析自己的会话） |
| 路径参数 | `sessionId`（即 `/session/start` 返回的 `session_1` 格式，兼容纯数字） |

**实现流程：** ① 解析 db 主键 + 归属校验（管理员可看任意） → ② **缓存判断**：`last_emotion_analysis` 非空且 `last_emotion_updated_at` 在 24 小时内 → 直接 `JSONUtil.toBean` 反序列化返回，不调 AI → ③ 缓存失效：`listBySession` 取全部消息 → 拼成「用户：xxx / AI：xxx」对话文本（超 8000 字符截尾保留最近部分） → ④ `chatClient.prompt().system(EMOTION_ANALYSIS_PROMPT).user(text).call().entity(EmotionAnalysis.class)` 结构化输出（overallMood/emotions/positiveRatio/summary/suggestions） → ⑤ 结果 JSON 写回 `consultation_session.last_emotion_analysis` + `last_emotion_updated_at=now` → ⑥ 返回。

**实现流程：** ① 解析主键 + `checkOwnership` 归属校验 → ② `deleteSession`：先 `deleteBySessionId` 删光该会话消息，再 `deleteById` 删会话（顺序删除，无外键也可干净清理） → ③ 返回成功。

## 六、快速自测清单（按顺序）

1. `POST /api/user/add` 注册一个 `userType=2` 的管理员 → `POST /api/user/login` 拿 token。
